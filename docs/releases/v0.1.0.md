## 📦 Description

Choose and apply individual Mac settings through a native Mac Tweak window.

## ✨ Changes

- Choose terminal tools, shell configuration, system preferences and custom keyboard/window behavior.
- Review exact changes, apply accepted fixes and verify saved settings.
- Browse saved configuration paths and keep current settings while cleaning app-generated temporary files and old copies, with filtered bulk selection, total selected size and explicit itemized acceptance.
- Use light/dark appearances, borderless color hovers, clear filled checkboxes, section colors, Heroicons and aligned About information.
- Open the chooser from Tweak.command or tweak.sh, with event-driven hover tracking and retained native scroll layers.
- Close and quit responsive native hosts; repeated source launches restore the existing window and selection.
- Relay terminal Ctrl+C to normal guarded app Quit from both public launchers, retaining active work and cleaning private session files.
- Run on Apple Silicon or Intel without an extra runtime for the chooser.
- Download the universal macOS ZIP or installer. This initial build is ad-hoc signed, with an unsigned installer, and is not notarized. Dock/launcher gestures require macOS 27; other components show their prerequisites.
- Add independent Wallpaper, Screen saver, Screen protection, Display and Power cards.
- Compact the Info window with even row spacing, keep Finder reveal silent on success, and fine-tune custom saver minutes with minus/plus buttons.
- Protect wallpaper/screen-saver services from global helper actions; preserve appearance by default.
- Keep native chrome visible with a frosted sidebar material and translucent surfaces that respect Reduce transparency.
- Make Mac Tweak participate in Dock/window tweaks through its regular native app identity.
- Name concrete changes before Apply, defer with Later, and show readable activity with colored before/after values.
- Clean validated legacy originals while the current helper keeps running; offer explicit recovery for abandoned app locks.

- Fix native Finder reveal and Trash, terminal progress and worker lock recovery; restore utility icons and use a compact footer.
- Guard native presentation and UI tests around protected screen-saver sessions; reject scripted visual-state writes.
- Load Wallpaper before the first screen-saver chooser to preserve its current Auto/Custom state, with bounded cancellable progress.
- Keep utility icons visible on macOS 27 and hover highlights aligned as result buttons move.

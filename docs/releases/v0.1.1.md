## 📦 Description

Install missing prerequisites with approval and improve Steam’s close-button support.

## ✨ Changes

- Offer Install or Later when tig or native helpers need Apple Command Line Tools. Mac Tweak opens Apple’s installer only after approval; Apple handles its download, license and administrator prompts.
- Check installation progress, support Check again and Stop waiting, and create a fresh review when the required tools are ready. Cancellation, changed selections, failures and timeouts do not approve tweaks.
- Name missing selected tools in the installation approval, and keep Review and Verify read-only.
- Support Steam’s custom close circle through its verified helper and parent app. Shift-click keeps the usual window-close behavior; QuitOnRed requests ordinary Quit and retains screen-saver protections.
- Add a read-only close-button audit for helper compatibility checks.
- Add isolated installation consent and failure coverage, plus native progress/control checks in light and dark appearances.

The app supports Apple Silicon and Intel. It is ad-hoc signed; the installer is unsigned and the artifacts are not notarized. Existing settings and storage paths are retained.
